# Unit 404 — Cyber Division (CDIV)

**CDIV is Fairytale's cybersecurity division.** We teach people to defend systems, and to test them only with permission.

- 📚 **Learn:** nine free courses in three tracks at **[unitcdiv.fairytale.ai](https://unitcdiv.fairytale.ai/)**
  - **Foundations:** risk, controls, cryptography, identity, architecture and governance
  - **Operations:** monitoring, detection, vulnerability management, threat hunting and incident response
  - **Offensive:** authorized assessment, practised only in a lab you own
- 🛠️ **Build:** lab environments, sample data and defensive tooling, published here under open licences
- 🌐 **Landing page:** [unitcdiv.github.io/.github](https://unitcdiv.github.io/.github/)

## Get involved

- **Found a mistake in a lesson?** [Open an issue](https://github.com/unitCDIV/.github/issues/new/choose) and pick the matching form.
- **Want to write or review a lesson?** Use the *Lesson proposal* form.
- **Contributing code?** Read the [contributing guide](https://github.com/unitCDIV/.github/blob/main/CONTRIBUTING.md).

## Ground rules

> **Authorized use only.** Never test a system without its owner's written authorization. Everything we teach about offensive security is practised in an isolated lab you build and own.
