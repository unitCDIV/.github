Fairytale · Unit 404 · Cyber Division

The open-source home of Unit 404.

CDIV is Fairytale’s cybersecurity division. We teach people to defend systems, and to test them only with permission. This page collects our public work on GitHub and explains how to take part.

Start learning at unitcdiv.fairytale.ai Browse our repositories

What we do

Teach

Nine free courses in three tracks, published at unitcdiv.fairytale.ai. Every course ends with an artifact you can show.

  • Foundations: risk, controls, cryptography, identity, architecture and governance
  • Operations: monitoring, detection, vulnerability management, threat hunting and incident response
  • Offensive: authorized assessment, practised only in a lab you own

Build in the open

Lab environments, sample data and small defensive tools that support the curriculum are published here on GitHub under open licences, so anyone can run, inspect and improve them.

Publish

Cohort announcements, technical write-ups and tooling releases go out on the CDIV blog. Lessons, including their code samples, are licensed CC BY-NC 4.0: reuse them non-commercially, with credit.

Get involved

The curriculum site’s source is maintained privately, so all public contributions start here, as issues and discussions on this repository. Maintainers turn accepted proposals and fixes into site changes.

Report a problem

Found a factual error, a broken link or an unclear explanation in a lesson? Open an issue and pick the matching form.

Propose or write a lesson

Courses marked “Soon” on the curriculum need authors and reviewers. Use the Lesson proposal form to agree on scope before you write.

Contribute code

Our public tool and lab repositories accept pull requests. Read the contributing guide first.

Learn with a cohort

Every course can be taken alone. Cohorts add a schedule, mentors and peer review. See Cohorts.

Ground rules

Authorized use only

Never test a system without its owner’s written authorization. Everything CDIV teaches about offensive security is practised in an isolated lab you build and own. That includes systems belonging to other participants, to Fairytale, and to GitHub.

  • Code of Conduct. Everyone in CDIV spaces agrees to it. Read the code.
  • Security reports. Report vulnerabilities privately, never in a public issue. Read the security policy.
  • Licences. Lessons, including their code samples, and other written content are CC BY-NC 4.0: non-commercial reuse with credit. The curriculum site’s own code is proprietary. Code in our public tool and lab repositories is MIT unless a repository says otherwise. See Licensing and attribution.
