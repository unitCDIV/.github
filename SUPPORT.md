# Getting help

## Where to go

| Question | Where |
|:--|:--|
| How do I start? Which course first? | The [curriculum](https://unitcdiv.fairytale.ai/curriculum/). Start with CDIV-F101 |
| A lesson has a mistake, or a page is broken | [Open an issue](https://github.com/unitCDIV/.github/issues/new/choose) |
| I'd like to write or review a lesson | Open a *Lesson proposal* issue |
| Cohorts and applications | The [Cohorts page](https://unitcdiv.fairytale.ai/cohorts/) and the [blog](https://unitcdiv.fairytale.ai/blog/) |
| A security problem with our site or repositories | The [security policy](SECURITY.md). Never a public issue |
| Behaviour that breaks the Code of Conduct | Contact a maintainer privately. See the [Code of Conduct](CODE_OF_CONDUCT.md) |

## What we can't help with

- Testing, scanning or accessing any system you don't own, or that you aren't authorized in writing to test. We won't answer questions about real-world targets.
- Recovering accounts, devices or data, or responding to an incident in your organisation. Contact your security team or a professional incident response provider.
- Certification exam questions.

## Response times

CDIV is run by a small team. We aim to triage new issues within a week. Security reports are acknowledged within five working days.
